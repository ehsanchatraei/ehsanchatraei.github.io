# Ehsan Chatraei Azizabadi · Academic website

The homepage presents research, eight selected publications, an open dataset, teaching and service, and contact information. The public academic CV lives at `cv.html` and supports browser printing.

## Preview

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript and has no installation or build step.

## GitHub Pages

For the personal site at `https://ehsanchatraei.github.io/`, place the files in the root of the `ehsanchatraei/ehsanchatraei.github.io` repository on `main`. In **Settings → Pages**, select **Deploy from a branch**, then **main** and **/(root)**. If the repository already exists, review its files and publishing source before committing changes.

## Updating content

Edit the homepage in `index.html`, the CV in `cv.html`, and the styles in `styles.css`. For each new publication, set the entry's `data-year` and update the year selector if needed. The list remains available when JavaScript is disabled.
